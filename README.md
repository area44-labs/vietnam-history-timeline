# Vietnam History Timeline

A chronological journey through modern Vietnam - from its independence declaration in 1945 to a dynamic, thriving nation in 2026.

Built with the beautiful and highly interactive [evilrabbit/lifeline](https://github.com/evilrabbit/lifeline) component layout.

## Development

Install dependencies:

```bash
pnpm install
```

Run local development server:

```bash
pnpm dev
```

Build for production:

```bash
pnpm build
```
